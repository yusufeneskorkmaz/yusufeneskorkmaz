Building tools for space-object characterization and rigorous AI-agent development.

- [glint-geo](https://github.com/yusufeneskorkmaz/glint-geo) — GEO satellite light curves from public ZTF images, with a 243-curve dataset.
- [glint-trace](https://github.com/yusufeneskorkmaz/glint-trace) — backward orbit traceback linking objects to documented launches.
- [agent-build-templates](https://github.com/yusufeneskorkmaz/agent-build-templates) — templates for rigorous multi-agent builds with AI coding tools.
